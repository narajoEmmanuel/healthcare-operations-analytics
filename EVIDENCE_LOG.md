## Evidence rules

- Do not record uninspected outputs as verified.
- Do not invent dimensions, checksums, findings, or impact metrics.
- Link claims to source artifacts and an earlier Git commit where possible.
- Use a later commit to register the SHA of the commit that created the evidence-producing artifact.
- State limitations and what each item does not prove.
